
# Smart Cap – An AI-Based Assistive Cap

Smart Cap is an AI-powered wearable assistive system designed to help people with visual difficulties in their everyday activities.

The system uses a camera mounted on a cap to capture the user's surroundings. It provides two main features: real-time object detection, which identifies common objects and selected object colours, and text reading, which recognises printed text and converts it into speech.

The recognised information is communicated through audio output using Bluetooth headphones. The user can switch between the two operating modes using the headphone controls.

The project combines embedded systems, computer vision, optical character recognition (OCR), and text-to-speech technology to explore an affordable assistive solution.
